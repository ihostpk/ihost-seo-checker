# iHost SEO Checker

**A Lightweight WordPress SEO Checker by iHost Pakistan**

Check essential on-page SEO elements with a simple, responsive WordPress plugin.

🌐 **Website:** https://www.ihost.com.pk/

## ✨ Features

- **SEO Title Check:** Review page title and character length.
- **Meta Description Check:** Check description availability and length.
- **H1 Heading Check:** Identify missing or multiple H1 headings.
- **Canonical URL Check:** Detect canonical link tags.
- **Robots Meta Check:** Review basic robots directives.
- **Image Alt Text Check:** Identify images with missing or empty alt attributes.
- **Link Text Check:** Flag common generic labels such as “Read More”.
- **HTTPS Check:** Verify whether the final webpage URL uses HTTPS.
- **Responsive Design:** Clean interface for desktop and mobile devices.

## 📦 Installation

1. Download or clone this repository.
2. Upload the `ihost-seo-checker` folder to your WordPress installation's `wp-content/plugins/` directory.
3. Activate **iHost SEO Checker** from the WordPress Plugins dashboard.
4. Create a page and add the shortcode:

   `[ihost_seo_checker]`

5. Publish the page and test a publicly accessible webpage.

## 📋 Requirements

- WordPress 5.8 or later
- PHP 7.4 or later
- A modern browser with JavaScript enabled

## ⚠️ Limitations

This plugin performs a basic browser-based on-page SEO review. Some websites block cross-origin browser requests (CORS), so they may not be accessible to the checker.

The results are not a complete SEO audit and do not measure backlinks, Core Web Vitals, Google indexing, or search rankings.

## 🔒 Privacy

- No API key is required.
- Submitted URLs and results are not stored in the WordPress database.
- No third-party analytics or tracking is included.
- Browser access restrictions may limit which websites can be checked.
